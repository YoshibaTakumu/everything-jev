# Changelog

## 0.1.0 — 2026-09-22

Initial public release:

- Typed Jev HTTP client with runtime validation, timeout and cancellation.
- Conservative suggestion/review/block policy with independent gates.
- 22 executable decision recipes and explicitly labelled offline fixtures.
- Dependency frontier, scoped memory eligibility and binary evaluation metrics.
- CLI, English/Japanese READMEs, integration guides and research source ledger.
- Credential-free tests and CI on Node.js 22 and 24.

Live inference quality and platform adapters are not validated or shipped as complete integrations in this release. No npm publication.
