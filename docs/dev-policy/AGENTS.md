# Development policy rules

- Before editing policy, read [the index](README.md), [document lifecycle](document-lifecycle.md) and [tooling rules](../../.claude/rules/tooling-ci.md).
- Keep policies consistent with [Contributing](../../CONTRIBUTING.md) and the actual scripts, hooks and workflows. A policy change does not itself configure automation or establish that a check passed.
- Keep the topic that owns a rule authoritative; `AGENTS.md` and `.claude/rules` provide short triggers and links. Preserve existing user authorization when applying a workflow.
