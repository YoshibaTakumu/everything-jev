# Research and source ledger

Research context assembled for the initial release on **2026-09-22**. External products, APIs and branches can change. Recheck official documentation before implementing an adapter. This is an independent synthesis; the code in this repository is original and does not vendor the projects below.

## Interpretation rules

“A public demo uses Jev” is evidence of an integration pattern, not a benchmark for our implementation or a guarantee that the integration is complete. Author-reported results belong to that author's dataset and conditions. We do not adopt their latency, accuracy, legal reliability or production-readiness claims as our own.

The cookbook extends these patterns into proposed designs. Unimplemented adapters are marked explicitly. The proposed applications are hypotheses until tested against the intended workload.

Jev's current interface supplies structured decisions over provided state. External storage supplies durable memory. Separate tools provide text/code generation, speech, visual interpretation, desktop control, media rendering and service writes. We found no basis to claim that it is the universal optimum for these systems.

## What remains unproven

No project-wide accuracy, speedup or cost reduction is claimed. We have not measured live Jev behavior on these recipes, certified security enforcement, shipped a persistent memory service, or connected the business and creative platforms. Those require domain-labelled evaluations and separate adapter tests. The executable fixtures prove that the local pipeline handles the supplied data, not that every proposed automation is ready for unattended operation.
