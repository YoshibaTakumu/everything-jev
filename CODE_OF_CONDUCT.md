# Code of Conduct

We welcome contributors with different backgrounds and levels of experience. Be respectful, assume good intent, and explain technical disagreements with evidence. Help others participate without harassment or intimidation.

Harassment, discriminatory abuse, threats, sexual harassment, deliberate disclosure of private information, and repeated disruption are not acceptable. These expectations apply in issues, pull requests, discussions and other spaces maintained by this project.

Maintainers may remove inappropriate content, close disruptive conversations, or restrict participation. Decisions should be proportionate, explain the behavior at issue where practical, and protect affected people's privacy.

For non-sensitive conduct concerns, use a repository issue without identifying private information. For sensitive concerns, contact the repository owner using a contact route they make available on their GitHub profile. This small project does not promise a dedicated moderation team or response-time guarantee.
